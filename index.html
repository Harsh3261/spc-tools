Sigma ⇄ PPM — capability in plain numbers

Convert between Cpk, expected defects (PPM) and yield. With the shift off, the process is treated as centred and PPM counts both spec tails. With the shift on, the Motorola 1.5σ-shift convention applies and the result is quoted as DPMO (one tail) — the convention behind "6 sigma = 3.4 DPMO".

True position — with MMC / LMC bonus

Enter how far the measured feature centre sits from its true (basic) position, the stated position tolerance, and the feature's actual mating size. Bonus tolerance is how far the actual size has departed from the MMC (or LMC) size limit.

Result

What this means: the diametral deviation 2√(Δx² + Δy²) is the diameter of the smallest zone around true position that contains the measured centre; it must fit inside the stated tolerance plus any bonus the feature's size has earned.

Geometry per ASME Y14.5 — exact diametral deviation, no statistical assumptions. All values in the same unit (mm or in) as entered.
